How the pipeline works

No one maps data columns. The REDCap data dictionary tells the pipeline what every field means.

  1. 1. Read the dictionaryQuestions, domains, sub-domains, countries, regions, priority items and level thresholds are derived from the REDCap data dictionary.
  2. 2. Export from REDCapThe REDCap API is called on a schedule, on a Data Entry Trigger and on demand. Only the fields the dashboard needs are requested. Personal contact details and free-text answers are never requested.
  3. 3. ScoreSub-domain, domain and overall scores and maturity levels are recalculated using ADHMAT V2.5 rules and checked against the scores REDCap calculated.
  4. 4. Store a snapshotEach change is saved as a snapshot, so a previous state can be restored. If a sync fails, the last good data stays on the dashboard.
  5. 5. Refresh the dashboardOpen dashboards are told about new data and redraw by themselves.

Administration

Enter the admin key to run a sync, upload a file or change settings. The key is shown once in the server console on first start and kept in data/admin.key. It stays in this browser tab only.
